# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - September 20, 2026

### 🚀 Initial Release
* Added multi-track piano roll visualization with 24-bit truecolor track themes.
* Added semitone piano keyboard ruler with white and black key styling.
* Added real-time playback synchronization and vertical playhead tracking.
* Added audio synthesis engine supporting SoundFont (.sf2) files via rustysynth and cpal.
* Added built-in polyphonic waveform synthesizer fallback for offline zero-config playback.
* Added multi-track sidebar with per-channel mute, solo, instrument labels, and selection indicators.
* Added bottom transport bar with elapsed time, bar/beat counter, BPM, volume, and interactive scrub bar.
* Added mouse and touch click support for scrubbing, mute/solo buttons, and track selection.
* Added keyboard shortcuts for zooming, pitch scrolling, measure seeking, and track navigation.
* Added built-in 4-track demo jam generator and `--info` CLI inspection mode.
